# PLP-Hackathon

A simple hackathon project repository showcasing a static website built with **HTML** and **CSS**.

## 🚀 About

This project was created for the PLP Hackathon. It demonstrates a basic web structure styled with CSS, ideal as a starter project or reference for beginners in frontend development.

## 📂 Project Structure

```
PLP-Hackathon/
├── index.html      # Main landing page
├── styles.css      # Styling for the webpage
├── Ian_CV.pdf      # Additional document resource
└── README.md       # Project documentation
```

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**

## ▶️ Getting Started

1. Clone the repo:

   ```bash
   git clone https://github.com/Ian-Joseph/PLP-Hackathon.git
   ```
2. Open `index.html` in your browser.

No extra dependencies are required.
